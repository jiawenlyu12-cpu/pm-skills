# Web 产品测试覆盖清单

> 执行测试时按这些类别逐项过。不是每项都适用每个产品 —— 先看页面有什么，再挑相关的测。
> 每发现一个偏差就记一条 bug（按 testing-knowledge.md 的 severity/priority 定级）。

## 1. 功能 / happy path（最高优先）
- [ ] 每个核心业务流程能从头走到尾（注册→使用→完成的主链路）
- [ ] 所有按钮、链接点击有正确响应，跳转到正确目标
- [ ] 表单能正常提交，提交后状态/数据正确更新
- [ ] CRUD：能创建、能看到、能编辑、能删除，且数据一致
- [ ] 搜索 / 筛选 / 排序 / 分页返回正确结果

## 2. 表单与输入校验（bug 重灾区，用边界值+等价类）
- [ ] 必填项留空 → 有明确错误提示，不允许提交
- [ ] 格式校验：邮箱、手机号、URL、日期格式非法时被拦截
- [ ] 边界值：最小/最大长度 ±1、0、负数、超大数、最大值
- [ ] 特殊字符 / emoji / 中英混排 / 前后空格
- [ ] 超长输入（粘贴 10000 字）不破坏布局、不报错
- [ ] 重复提交 / 快速连点不产生重复数据
- [ ] 错误提示信息准确、可读、指向具体字段
- [ ] 提交中按钮置灰 / loading，防二次提交

## 3. 导航与链接
- [ ] 所有导航项可达，无死链 / 404
- [ ] 浏览器前进/后退按钮行为正常，不丢状态
- [ ] 刷新页面后状态保持合理（不该丢的别丢）
- [ ] 深链接（直接访问内页 URL）可正常加载
- [ ] 面包屑 / 返回逻辑正确

## 4. 鉴权与权限（如有登录）
- [ ] 未登录访问受保护页面 → 跳登录，不泄露内容
- [ ] 登录 / 登出 / 会话过期处理正确
- [ ] 错误密码、不存在账号有正确提示（但不暴露"账号是否存在"）
- [ ] 越权：A 用户能否访问 B 用户的数据（改 URL 里的 id）
- [ ] 登出后浏览器后退不能看到敏感页面

## 5. 状态与数据
- [ ] 空状态（无数据时）有友好提示，不是空白/报错
- [ ] 加载状态（loading / skeleton）存在
- [ ] 大数据量下列表/表格不卡、分页正常
- [ ] 数据在不同页面间一致（一处改，处处更新）

## 6. 错误处理与健壮性
- [ ] 断网 / 慢网下有提示，不无限转圈
- [ ] 接口报错（4xx/5xx）有用户可理解的提示，不暴露堆栈
- [ ] 异常输入不导致页面崩溃 / 白屏
- [ ] 超时有兜底

## 7. 响应式与兼容（用 browser_resize 切断点）
- [ ] 手机（375px）、平板（768px）、桌面（1440px）布局正常
- [ ] 无横向滚动条、无元素重叠/溢出/截断
- [ ] 触摸目标够大、菜单在移动端可用（汉堡菜单等）
- [ ] 图片不变形、不拉伸

## 8. 可访问性（a11y，WCAG 基线）
- [ ] 所有图片有 alt；图标按钮有 aria-label
- [ ] 纯键盘可完成核心操作（Tab 顺序合理，焦点可见）
- [ ] 表单 label 与控件正确关联
- [ ] 文字与背景对比度达标（正文 ≥ 4.5:1）
- [ ] 颜色不是唯一的信息传达方式

## 9. 性能与技术健康（每个页面都查）
- [ ] **Console 无 error / 无未捕获异常**（用 browser_console_messages）
- [ ] **网络请求无 4xx/5xx 失败**（用 browser_network_requests）
- [ ] 首屏加载不过慢（主观 > 3s 记一条）
- [ ] 无明显布局抖动（CLS）、无资源 404

## 10. 内容与文案
- [ ] 无错别字 / 占位符残留（Lorem ipsum、TODO、undefined、null、NaN）
- [ ] 文案前后一致（同一概念别用两个词）
- [ ] 金额、日期、数字格式正确且本地化

---

## 探索性测试（脚本之外，靠"破坏欲"）
跑完清单后，花几分钟当"恶意用户"乱玩：
- 不按预期顺序操作（先点第 3 步）
- 同时开两个标签页操作同一数据
- 在加载途中疯狂点击 / 切换
- 改 URL 参数试探
- 输入领域里最离谱的数据
